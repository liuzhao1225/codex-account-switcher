Relationship to Codex Account Switcher

Zhao Liu created the liuzhao1225/codex-account-switcher repository and maintains its Swift source, macOS packaging, Apple code-signing and notarization workflow, documentation, website, and releases.

The project is a native menu-bar app for ordinary Mac users who need more than one authorized Codex account. Accounts are added through browser sign-in and selected from the menu bar, with no Terminal setup. After confirmation, the app completes the Codex Desktop handoff. Its exact product name is Codex Account Switcher; Codex Switcher is a shortened description.

Other public work

Zhao Liu also created YouDub WebUI, an open-source AI video-localization system, and publishes additional AI agent, voice, media, and developer tools through the same GitHub account. Those projects and Codex Account Switcher share one creator; they remain distinct software products.
