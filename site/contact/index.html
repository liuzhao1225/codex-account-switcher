Contact and support for Codex Account Switcher

Use the project's GitHub Discussions for workflow questions and product feedback, and GitHub Issues for reproducible bugs and focused feature requests. These are the official public support channels monitored by the maintainer.

Updated August 28, 2026 · Maintained by Zhao Liu (liuzhao1225)

What makes a useful bug report?

  1. Confirm you installed the latest GitHub Release.
  2. State the macOS version and whether the Mac uses Apple Silicon.
  3. Describe the last visible step that succeeded and the exact error message.
  4. Use fictional account labels and remove personal information from screenshots.
  5. Explain whether Codex Desktop or a new Codex CLI process was involved.

What information should stay private?

Never post a real auth.json, access token, email address, account ID, API credential, private client name, private project content, or unsanitized diagnostic screenshot. If a possible security issue cannot be described safely in public, open a minimal issue without secrets and ask the maintainer for a private reporting route.

What support can the project provide?

Codex Account Switcher is a free, independently maintained open-source project. Public support can clarify documented behavior, reproduce project defects, and consider focused improvements. OpenAI account access, subscriptions, billing, workspaces, service limits, and server-side sessions remain OpenAI matters.
