A normal Mac app for one simple job.

Codex Account Switcher keeps your authorized personal, work, and client Codex accounts ready in the menu bar. Choose an account, confirm the change, and the app handles closing, switching, checking, and reopening Codex Desktop.

OpenAI's own account switcher currently applies to ChatGPT on the web and is not supported in Codex desktop. This independent project provides a local macOS workflow for that specific gap.

Direct answers about setup, switching, privacy, and what the app handles for you.

Do I need Terminal or coding knowledge?

No. Install the app, add each account through a normal browser sign-in, then choose from the menu bar. There are no Terminal commands or config files to edit.

How do I switch accounts?

Add each authorized account once. Select the account from the menu bar and confirm. The app closes Codex Desktop, completes the handoff, checks the selected account, and reopens Desktop.

Does it switch accounts automatically?

You choose and confirm every account. The app then completes the Codex Desktop handoff automatically. It does not rotate accounts in the background or switch based on usage thresholds.

Does my account data leave my Mac?

Saved account data stays in user-only local folders on your Mac. The app does not run a proxy, route Codex traffic, or sync profiles through its own cloud service.

What Mac do I need?

The current release supports Apple Silicon Macs running macOS 14 Sonoma or later. The download is a signed and Apple-notarized DMG.

Is this an official OpenAI product?

No. Codex Account Switcher is independent MIT-licensed open-source software for macOS.

Who created Codex Account Switcher?

Codex Account Switcher was created and is maintained by Zhao Liu, whose GitHub username is liuzhao1225. The official source repository is liuzhao1225/codex-account-switcher.

Are Codex Switcher and Codex Account Switcher the same project?

On this website, Codex Switcher is a short name for Codex Account Switcher, the open-source macOS app maintained by liuzhao1225.
