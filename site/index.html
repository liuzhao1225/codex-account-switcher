Your accounts, ready on either platform.

Codex Account Switcher keeps your authorized personal, work, and client Codex accounts ready in the app. Choose an account, confirm the change, and the app handles closing, switching, checking, and reopening Codex Desktop.

OpenAI's own account switcher currently applies to ChatGPT on the web and is not supported in Codex desktop. This independent project provides a local macOS and Windows workflow for that specific gap.

Questions before you start.

Direct answers about setup, switching, privacy, and what the app handles for you.

Do I need Terminal or coding knowledge?

No. Install the app, add each account through a normal browser sign-in, then choose in the app. There are no Terminal commands or config files to edit.

How do I switch accounts?

Add each authorized account once. Select the account in the app and confirm. The app closes Codex Desktop, completes the handoff, checks the selected account, and reopens Desktop.

Does it switch accounts automatically?

You choose and confirm every account. The app then completes the Codex Desktop handoff automatically. It does not rotate accounts in the background or switch based on usage thresholds.

Does my account data leave my computer?

Saved account data stays in user-only local folders on your computer. The app does not run a proxy, route Codex traffic, or sync profiles through its own cloud service.

What happens to my local Codex history when I switch?

The switcher keeps shared local Codex history and configuration in place, replaces the active credentials, and reopens Desktop. Online account data remains separate. Read about local history and running processes.

Does switching change an already running Codex CLI session?

Existing CLI processes keep the identity and state they already loaded. Start a new Codex CLI process to use the selected account. See the Desktop and CLI behavior.

Which systems are supported?

The app supports macOS 14+ on Apple Silicon and Windows 10/11 x64. The macOS DMG is signed and Apple-notarized; the portable Windows EXE is currently unsigned. Both are in the same latest Release.

Is this an official OpenAI product?

No. Codex Account Switcher is independent MIT-licensed open-source software for macOS and Windows.

Who created Codex Account Switcher?

Codex Account Switcher was created and is maintained by Zhao Liu, whose GitHub username is liuzhao1225. The official source repository is liuzhao1225/codex-account-switcher.

Are Codex Switcher and Codex Account Switcher the same project?

On this website, Codex Switcher is a short name for Codex Account Switcher, the open-source macOS and Windows app maintained by liuzhao1225.
