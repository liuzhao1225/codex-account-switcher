Codex Account Switcher 隐私说明

Codex Account Switcher 把账号列表、已保存凭证、设置和用量缓存保存在你的 Mac 上。项目不运营账号代理、流量路由、分析服务或云端账号配置后台。

更新于 2026 年 9 月 5 日 · 由刘朝 Zhao Liu（liuzhao1225）维护 · 适用于 v0.1.7

隐私模式是什么？

应用使用仅限当前用户访问的本地文件，也不会把已保存账号配置上传到开发者运营的服务器。浏览器登录、身份检查和用量刷新使用 OpenAI Codex 的登录或 app-server 流程，并继续受 OpenAI 服务及政策约束。

Mac 本地保存哪些数据？

本地文件保存内容用途
accounts.json配置 ID、显示名称、可选邮箱和账号 ID、时间及当前配置 ID显示并识别已保存账号
accounts/<profile-id>/auth.json获准使用账号的可复用 Codex 凭证快照激活用户选择的账号
settings.json语言和显示偏好保留应用设置
usage-cache.json配置 ID、最近一次成功的每周用量、可选 5 小时用量、重置时间和获取时间刷新时继续显示用量信息

这些文件位于 ~/Library/Application Support/Codex Account Switcher/。账号配置目录权限为 0700，凭证和 registry 文件权限为 0600。Codex 当前凭证仍位于活动 CODEX_HOME，通常是 ~/.codex/auth.json。

会发生哪些网络活动？

Codex Account Switcher 没有开发者运营的 API 或云端配置同步服务。添加账号会启动标准 Codex 浏览器登录；身份验证和用量刷新会为对应本地配置启动 Codex app-server，它可能与 OpenAI 通信。切换器不会成为 Codex 与 OpenAI 之间的代理。

本网站是 GitHub Pages 静态网站，没有项目自行添加的分析脚本、广告跟踪、账号系统或联系表单。GitHub 可能依据其隐私声明处理正常的网站托管请求数据。

0.1.7 使用 Sparkle 每小时查询 GitHub Releases 更新源，并在用户选择更新后下载安装包。GitHub 及下载服务方会收到普通 HTTPS 请求元数据。更新请求不附带已保存账号的凭据，Sparkle 系统信息采集已关闭。可在设置中关闭自动检查。

如何删除本地数据？

  • 在“管理账号”中移除非当前账号，可删除对应配置、元数据和用量缓存。
  • 退出并卸载应用后，删除 ~/Library/Application Support/Codex Account Switcher/，可清除切换器管理的全部本地数据。
  • 活动 ~/.codex/auth.json 和服务端会话应通过 Codex 与 OpenAI 账号管理。删除切换器数据不会自动撤销所有 OpenAI 会话。

反馈问题时哪些信息不能公开？

请勿把真实 auth.json、访问令牌、账号名称、邮箱、API 凭证、私人截图和私人项目内容放入 GitHub Issue、Discussion、提交或测试数据。有效的问题报告可以包含应用版本、macOS 版本、可见错误阶段和脱敏复现步骤。

如何核验这些说明？

  • 系统设计本地文件、权限、app-server、切换顺序和删除行为。
  • AccountStore.swift账号配置、registry、设置、用量缓存与凭证存储实现。
  • OpenAI Codex 认证存储CODEX_HOME 下文件型 auth.json 的上游实现。
