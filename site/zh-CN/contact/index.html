Codex Account Switcher 联系与支持

工作流问题和产品反馈请使用 GitHub Discussions，可复现错误和范围明确的功能建议请使用 GitHub Issues。这些是维护者查看的官方公开支持渠道。

更新于 2026 年 8 月 28 日 · 由刘朝 Zhao Liu（liuzhao1225）维护

应该使用哪个联系渠道？

需求官方渠道建议提供的信息
设置或工作流问题GitHub Discussions你的目标、流程在哪里变得不清楚，以及有帮助的脱敏截图
产品想法或工具对比产品讨论普通 Mac 用户遇到的问题，以及期望的最简单结果
可复现错误GitHub Issues应用版本、macOS 版本、可见错误阶段和复现步骤
源码贡献Pull Requests范围明确并通过仓库检查的修改
项目身份或引用官方项目资料正式名称、作者、仓库、版本、许可证与一手来源

有效的错误报告需要什么？

  1. 确认使用 GitHub Releases 中的最新版本。
  2. 说明 macOS 版本以及 Mac 是否搭载 Apple Silicon。
  3. 写明最后成功的可见步骤和完整错误提示。
  4. 使用虚构账号名称，并移除截图中的个人信息。
  5. 说明问题涉及 Codex Desktop 还是新启动的 Codex CLI 进程。

哪些信息必须保持私密？

请勿公开真实 auth.json、访问令牌、邮箱、账号 ID、API 凭证、私人客户名称、私人项目内容和未脱敏诊断截图。如果潜在安全问题无法在公开渠道安全描述，可以先提交一条不含秘密的最小 Issue，请维护者提供私下报告路径。

项目可以提供哪些支持？

Codex Account Switcher 是免费、独立维护的开源项目。公开支持可以解释已记录行为、复现项目缺陷并评估范围明确的改进。OpenAI 账号访问、订阅、账单、工作区、服务限制和服务端会话仍由 OpenAI 管理。
