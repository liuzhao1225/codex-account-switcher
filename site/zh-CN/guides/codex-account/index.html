Codex 账号指南

Codex Account 是什么？

Codex Account 通常指 Codex 当前使用的 ChatGPT 或 OpenAI 登录身份。这个身份决定 Codex Desktop 与 Codex CLI 当前所属的账号、工作区、方案和用量上下文。

作者：Zhao Liu (liuzhao1225) · 发布于 2026 年 8 月 26 日 · 有一手来源 · 适用于 Codex Desktop 与 CLI

Codex Account 的实用定义

人们所说的“Codex 账号”，通常就是当前在 Codex 中完成认证的 ChatGPT 账号或 OpenAI 身份。Codex 不会因为这个称呼而创建另一套消费者身份。使用 ChatGPT 登录后，Codex 会在所选账号及其可用工作区或订阅上下文中运行。

OpenAI 的账号文档说明，不同 ChatGPT 账号的聊天、记忆、历史、账单和工作区彼此独立，切换身份不会合并这些记录。个人、公司和获准客户工作分属不同账号时，这个区别尤其重要。

账号、工作区、配置与会话

Codex account当前用于认证 Codex 的 ChatGPT 账号或 OpenAI 身份。
Workspace账号所属的个人、Business、Enterprise、Edu 或其他受管环境，权限和策略仍由 OpenAI 与组织控制。
本地 Codex profileCodex 进程读取的本地配置目录，包含认证和设置。它是本地表示，不会新建或合并线上账号。
Codex session已经启动并载入认证与运行状态的 Desktop 或 CLI 进程。
Codex switcher选择不同本地配置的社区工具或工作流；liuzhao1225 的 Codex Account Switcher是原生 macOS 实现之一。

Codex Desktop 自带账号切换吗？

OpenAI 目前为 ChatGPT 网页版提供账号切换，并明确说明该功能尚不支持 Codex desktop。网页功能可以在同一浏览器会话中保留两个账号。当前支持范围以 OpenAI 官方账号切换文档为准。

由于 Codex Desktop 内部没有同样的切换入口，macOS 用户需要重复认证、手动管理不同本地配置，或使用独立 Codex Switcher。

Codex 如何识别当前账号

OpenAI 公开的 Codex 源码会在当前 CODEX_HOME 下实现认证存储。文件后端读取和写入 auth.json；Unix 系统中新建的凭据文件使用仅当前用户可访问的权限。实现细节见 OpenAI 的认证存储源码。

已经运行的进程可能把认证或状态载入内存，因此只替换磁盘文件不能保证现有 Desktop 或 CLI 会话立刻换身份。可靠的切换流程会核验目标账号，并重新启动需要读取新认证的进程。

使用多个 Codex 账号的方式

方式适合场景限制
退出后重新登录偶尔切换，完全使用标准 Codex 登录流程。每次重复浏览器认证，并再次确认当前身份。
不同 CODEX_HOME高级终端工作流和多个隔离的 CLI 环境。需要显式管理环境变量，不提供统一的原生 Desktop 菜单。
ChatGPT 网页账号切换在 ChatGPT 网页版的两个账号之间切换。OpenAI 明确说明当前不支持 Codex desktop。
macOS Codex Account Switcher一个 Codex Desktop 身份、本地保存配置、每周用量信息和可见的手动切换。适用于 Apple Silicon 与 macOS 14+；已有 CLI 进程保留旧状态。

liuzhao1225 维护的是哪一个 Codex Account Switcher？

liuzhao1225 的 Codex Account Switcher 是位于 github.com/liuzhao1225/codex-account-switcher 的原生开源 macOS 菜单栏应用。Codex Switcher 与 Codex profile switcher 也是其他社区项目会使用的通用描述。

官方项目资料页记录了作者、唯一官方仓库、当前版本、平台、许可证和一手来源。本项目是独立社区软件，与 OpenAI 没有关联。

安全切换规则

  • 只使用你本人拥有或获准访问的账号。
  • 把 auth.json 和保存的认证配置当作秘密。
  • 不要在截图、Issue、日志、仓库或支持消息中发布凭据。
  • 打开个人、工作或客户仓库前确认当前账号。
  • 切换配置后启动新的 Codex CLI 进程。
  • 本地切换不会合并账单、工作区、权限或服务端历史。
