Codex Account Switcher/多账号切换

Codex 账号切换指南

macOS Codex 多账号切换完整指南

一次保存个人、工作与客户 Codex 登录信息，比较每个账号的每周用量，再从原生 macOS 菜单中选择当前账号，无需每次重复完整的浏览器登录流程。

作者：Zhao Liu (liuzhao1225) · 更新于 2026 年 8 月 26 日 · 阅读约 7 分钟 · 适用于 Apple Silicon 与 macOS 14+

为什么 Codex 多账号使用容易变得繁琐

开发者常常把个人项目、公司工作区和获准使用的客户项目放在不同 ChatGPT 账号中。Codex Desktop 与 Codex CLI 会读取一个当前认证文件，手动更换身份往往需要退出登录、打开浏览器、重新完成认证，再确认当前到底使用了哪个账号。

Codex Account Switcher 为每个已保存身份保留相互独立的本地认证快照。在切换前，菜单直接显示当前账号、每周剩余用量与重置时间。

请只使用你本人拥有或获准访问的账号。应用提供本地账号选择流程，不会改变 OpenAI 账号权限、账单、工作区策略或用量限制。

OpenAI 当前支持范围

OpenAI 官方文档说明账号切换目前用于 ChatGPT 网页版，并明确说明该功能尚不支持 Codex desktop。macOS Codex 用户因此需要重复认证、手动管理不同本地配置，或使用独立切换器。

有一手来源的 Codex Account 指南解释账号身份、CODEX_HOME、auth.json、Desktop 会话与 CLI 会话的关系。官方项目资料页记录本应用、作者和唯一官方仓库。

开始前需要准备什么

  • 搭载 Apple Silicon、运行 macOS 14 Sonoma 或更高版本的 Mac。
  • Codex Desktop、Codex CLI，或同时安装两者。
  • 至少两个可以使用 Codex 的 ChatGPT 账号。
  • 从 GitHub Releases 下载的最新签名并经过 Apple 公证的 Codex Account Switcher DMG。

把应用移入“应用程序”并启动一次。切换器会出现在 macOS 菜单栏中，也可以设置为登录 Mac 后自动启动。

第一步：一次保存每个 Codex 账号

保存 Codex 当前正在使用的账号

打开管理账号并导入当前 Codex 登录状态。应用会读取当前配置中的身份，并以用户专属权限保存本地快照。

添加另一个个人、工作或客户账号

选择添加账号。切换器会在新的本地配置目录中启动标准 Codex 登录流程，因此添加账号时不会覆盖当前正在使用的配置。完成浏览器登录后，为账号设置清晰名称。

对每个获准使用的身份重复这一过程。菜单会把所有已保存账号放在一起，并用整行高亮标记当前账号。

第二步：比较 Codex 每周用量

开始长时间 Codex 任务前打开菜单。每个账号行都会显示每周剩余百分比与对应重置时间。成功获取的用量会缓存在本地，刷新过程中继续显示，拿到新数据后再更新。

这些信息帮助你在切换前做决定。应用不会推荐账号，也不会自动轮换配置；最终选择始终由你完成。

第三步：切换当前 Codex 账号

  1. 选择一个当前没有高亮的已保存账号。
  2. 阅读确认页面中关于 Codex Desktop 与 CLI 的影响说明。
  3. 确认切换。
  4. 应用依次保存当前配置、激活所选认证、验证所选身份，并重新打开 Codex Desktop。

整个操作按明确顺序执行。任一阶段失败时，切换会立即停止并显示原始错误，方便准确定位问题发生的位置。

Codex Desktop 与 CLI 会发生什么

Codex Desktop 会在确认切换后关闭并重新打开。Desktop 中正在运行的任务可能在交接时停止，因此建议在开始重要工作前完成切换。

已经运行的 Codex CLI 进程会保留此前加载的状态。切换器不会终止它们。需要让终端使用新账号时，请启动一个新的 Codex CLI 进程。

账号配置保存在哪里

Codex 当前认证文件仍位于 ~/.codex/auth.json。OpenAI 公开的 Codex 认证存储源码显示，文件后端会在当前 CODEX_HOME 中读取和写入 auth.json。切换器保存的账号配置与元数据位于 ~/Library/Application Support/Codex Account Switcher/。

应用完全在本机运行，账号目录仅供当前用户访问，也不使用账号代理、流量路由、云端配置同步或自动账号轮换。删除非当前账号时，只会删除切换器中的本地副本，不代表撤销所有服务端会话。

选择适合你的多账号方式

当一个 Codex Desktop 实例需要在某个时刻使用一个明确身份时，菜单栏切换器会很合适。如果需要让多个 Codex 进程同时使用不同账号，分别设置 CODEX_HOME 或使用隔离的应用环境可能更适合。

Codex Account Switcher 专注于前一种工作流：用量清晰可见、切换由用户手动确认、没有后台账号路由。
